# LUT Lab

ブラウザだけで写真から `.cube` 形式の3D LUTを書き出すWebアプリです。

## 機能

- before / after 画像ペアから色差分を解析して LUT を生成
- after 画像のみから色傾向を推定して LUT を生成
- 複数画像による平均化
- LUT適用プレビュー
- 17 / 33サイズの `.cube` 書き出し
- 輝度トーンカーブ推定
- 強度 0-300%

## 使い方

`index.html` をブラウザで開くだけで動きます。

ローカルサーバーで確認する場合:

```bash
npx serve .
```

## 精度について

before / after 方式は、同じ構図・同じ被写体・近い露出のペアほど良い結果になります。複数ペアを使うと、写真固有の偏りを減らして共通の色変換を抽出しやすくなります。

afterのみ方式は、元画像が分からないため厳密な復元ではありません。画像の平均色、トーン、彩度、シャドウ/ハイライトの色傾向から「近いルック」を作る推定方式です。

Log素材に当てる場合は、強度を 180-300% まで上げると変化が見えやすくなります。強くすると白飛びや色転びも起きやすくなるため、before / after ペアを複数使うのがおすすめです。
