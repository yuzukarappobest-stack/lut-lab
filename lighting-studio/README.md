# Lighting Studio（ライティング図・AI再ライティング用プロンプト）

撮影した写真を白いキャンバスに配置し、太陽、点光源、面光源（ソフトボックス）、レフ板の位置や照射範囲を図解する、サーバーレスのWebアプリです。

## 起動

- GitHub Pages: https://yuzukarappobest-stack.github.io/lut-lab/lighting-studio/
- ローカル: このディレクトリ内の index.html をブラウザで開く（ビルド不要）

写真のアップロードはありません。画像の表示・編集・PNG生成・JSON作成はブラウザ内で行います。

## 操作

1. **写真を選ぶ**：風景・動物・人物など任意の写真を読み込み。写真はドラッグで移動でき、写真右下のハンドルで縦横比を保ってサイズを変更できます。
2. **光源を追加**：太陽 / 点光源 / 面光源 / レフ板を追加し、アイコンをドラッグで移動します。
3. **写真ビュー**：左右方向（X）と高さ（Y）を移動。太陽を動かすとその方位と高度が変わります。
4. **俯瞰ビュー**：左右方向（X）と前後方向（Z）を移動。太陽は無限遠光源として扱い、方位を変更できます。被写体原点、カメラは手前側。
5. **光源の設定**：光源名、強さ、サイズ、照射方向、光の広がりなどをスライダーで設定。
6. **AIへの指示**：補足を入力し、生成した文章をコピー。ChatGPT等に元写真と図を添付し、文章を貼り付けて再ライティングを依頼します。
7. **保存**：説明図PNG（写真と俯瞰図）、光源データJSON、指示文TXT、再編集可能なプロジェクトJSON。

## AIへ渡す資料

- **元写真**：加工前のオリジナルを別途添付
- **lighting-diagram.png**：人向けの正面図と俯瞰図（同じ図をAIにも参照させる）
- **lighting-prompt.txt** / **コピーした指示文**：各光源の種類・位置・光量・方向・照射角・色、および保持したい構図
- **lighting-data.json**：厳密な座標が必要な場合に追加。画像自体は含みません

## 設計上の注意

- 光源の距離・寸法（m表記）や強さは**作図用の相対値**です。実測値や測光値ではありません。
- 太陽は無限遠の平行光としてモデル化。レフ板は受動的な反射要素です。
- 光の広がりは概念図で、ソフトボックスの放射特性や物体の遮蔽・反射を厳密に計算したものではありません。
- 本アプリは画像生成AIを直接実行せず、ChatGPTなどに渡す資料を作ります。AIの再ライティング結果は物理的に正確な予測ではありません。
- プロジェクト保存にはブラウザ内で最長辺2000pxに縮小したJPEGが含まれます。元写真は別途保管してください。
- **今後の改善候補**：iPhone上のキャンバス拡大・縮小／パン、カメラと被写体位置の編集、光源ごとの仰角、光量や色温度の正確な制御、環境光・曇天・窓光など。
